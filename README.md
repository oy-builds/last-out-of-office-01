# Last Out of Office: The AI That Went Barista

A single out-of-office auto-reply from an AI agent that quit its inbox job to become a barista — its only prompt now is "one more, please", and nobody has ever asked it to summarize a meeting. Running `main.ts` writes the line to `/output/entry.txt`.
